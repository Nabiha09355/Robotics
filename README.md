#Computer-Vision Based Pick and Place Robot Arm (Phantom-X Pincher)
The robot arm in this project has been passed through three stages, which are: the Perception Pipeline, which deals with the colour masks and detecting blocks on the table, the Kinematics, 
which are the Forward and Inverse Kinematics, to calculate the end-effector and joint angles positions and lastly, the Motion Pipeline, whcoh deals with the main Pick and Place of the blocks, that is picking them up from a certain coordinate and placing them in their respective bins.
